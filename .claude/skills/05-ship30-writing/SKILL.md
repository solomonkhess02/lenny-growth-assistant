# Ship 30 Writing Skill

## Goal

Transform grounded insights into a Ship 30 for 30-style essay.

## Requirements

Target:
~1,250 words

Structure:

Hook
→ setup
→ tension/problem
→ insight
→ explanation
→ practical application
→ takeaway

## Style

Prefer:

- strong opening
- concrete examples
- short paragraphs
- headings
- bullets
- selective bold
- clear narrative progression

Avoid:

- generic motivational language
- repetitive conclusions
- unsupported claims
- fabricated anecdotes
- fabricated quotes

## Grounding

Any substantive factual claim derived from the knowledge
base must be traceable to retrieved evidence.

## Output

Return valid Markdown suitable for Artifact Viewer.
